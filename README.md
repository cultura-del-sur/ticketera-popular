# Ticketera Popular

Ticketera Popular is being planned as a ticket sales and event promotion platform for independent, community-run cultural spaces. The intended system has a Django REST API, a Next.js web app, and an Expo app for QR ticket check-in.

This `development` branch is the clean starting point for the new implementation. It currently contains BMad tooling and planning artifacts, with no application code.
