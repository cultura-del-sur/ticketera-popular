- (decision) Visión del producto: venta de entradas y promoción de eventos para espacios culturales comunitarios, independientes, autogestivos y de bajos recursos.
- (decision) Tres aplicaciones previstas: backend Django con API REST; plataforma web Next.js para promoción y venta; app React Native con Expo para escanear y registrar el ingreso mediante QR impreso o en teléfono.
- (decision) La implementación nueva debe partir desde cero; el código actual en development sirve como referencia de decisiones de arquitectura, modelo de datos y lógica de dominio, no como base a reutilizar.
- (change) Antes de reiniciar development, el usuario quiere conservar su estado actual en una rama de archivo o respaldo; nombre y procedimiento pendientes de definir.
